# 使用ライブラリとライセンス

最終確認日: 2026-08-18

## 方針

**コピーレフト系（GPL / LGPL / AGPL）のコードを公開物に含めない。**

## 確認方法

```
npx license-checker-rseidelsohn --summary --production
```

## 実際に公開されるファイルに含まれるもの

ブラウザに配信されるのは `out/` フォルダの中身だけです（全55ファイル・約2.0MB）。
ここに含まれるのは、以下のライブラリから生成されたJavaScriptとCSSです。

| ライブラリ | 役割 | ライセンス |
|-----------|------|-----------|
| next | アプリの土台 | MIT |
| react / react-dom | 画面の描画 | MIT |
| tailwindcss | スタイル | MIT |
| three | 3Dの宝箱 | MIT |
| @react-three/fiber | ReactとThree.jsの橋渡し | MIT |
| @react-three/drei | Three.jsの補助 | MIT |
| zustand | 状態の保存 | MIT |

**いずれも MIT ライセンスで、コピーレフト系は含まれていません。**

フォントは外部から一切読み込まず、端末に入っているフォントのみを使用しています。
3Dモデル・画像素材も使っておらず、宝箱はすべてコードで組み立てています。

## 依存ツリーに現れるが、公開物には含まれないもの

`--production` での集計に以下が現れますが、いずれもビルド作業中にだけ使われるもので、
`out/` には一切含まれません（`grep -rl "sharp\|libvips" out/` で混入なしを確認済み）。

| パッケージ | ライセンス | 公開物に含まれない理由 |
|-----------|-----------|----------------------|
| `@img/sharp-win32-x64` | Apache-2.0 AND **LGPL-3.0-or-later** | Next.js の画像最適化サーバー用の部品。本アプリは `images: { unoptimized: true }` で画像最適化を使わないため、実行されず配信もされない |
| `caniuse-lite` | CC-BY-4.0 | ブラウザ対応表のデータ。ビルド時にCSSの書き方を決めるためだけに参照される |

`@img/sharp-*` は Next.js が任意依存として宣言しているため、意図せずインストールされます。
**公開されるサイトにこのコードは入りません** が、この事実は公開前に毎回確認してください。

## カード画像について

`public/cards/` に置く写真は、**必ず利用許諾を得たものを使用してください。**
撮影者・提供元を記録し、必要に応じてアプリ内にクレジットを表示できるようにしておくことを推奨します。
